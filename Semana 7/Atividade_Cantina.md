# Sistema de Vendas da Cantina Escolar

## 1. Casos de Uso

### Atores
- Cliente
- Atendente
- Gerente

### Principais funcionalidades
- Consultar cardápio
- Realizar venda
- Realizar pagamento
- Emitir comprovante
- Gerenciar produtos
- Atualizar estoque
- Consultar vendas
